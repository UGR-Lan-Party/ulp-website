# Entorno y revisión de dependencias

Revisión de 14 de octubre de 2026. Node 24.21.0 LTS y pnpm 10.34.7 están fijados para desarrollo, CI y Docker. Node 24.22.0 acababa de publicarse en nodejs.org, pero no estaba disponible en el paquete npm `node`; se eligió la versión comprobable disponible también en la imagen oficial. Actualizar el parche de forma coordinada cuando esté disponible en todos los entornos.

Se aplican actualizaciones compatibles con los rangos existentes. `@astrojs/check` se actualiza de forma explícita; el nuevo comprobador detectó dos defectos de sintaxis previos que se corrigen. Sharp se actualiza a 0.35.5 también en Astro mediante una única sustitución dirigida, verificada con la compilación. Los únicos scripts de instalación permitidos son los de esbuild y Sharp.

Se retira `astro-compress`: Astro ya minimiza JS/CSS y el HTML; las imágenes adaptadas se generan explícitamente. Esto evita recomprimir los originales para descarga en cada build y reduce el grafo de herramientas. La generación de variantes se ejecuta con `pnpm images`.

`pnpm audit --json` pasa de 99 avisos (8 bajos, 34 moderados, 56 altos y 1 crítico) a 13 (3 bajos, 6 moderados, 3 altos y 1 crítico). Son avisos del grafo, no trece vulnerabilidades demostradas en producción. No se ocultan ni se desactiva la auditoría.

## Comprobación

Instalación con `--frozen-lockfile`, pruebas, `astro check` y build normal con las versiones fijadas. La compilación ya no necesita una configuración especial que omita la recompresión. Docker no está instalado en el equipo de desarrollo: su construcción queda a cargo de CI/operación y no se declara ensayada localmente.
